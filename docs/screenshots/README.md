# Screenshots Directory

This directory is for storing screenshots and GIFs that showcase the Zaglot application.

## Adding Screenshots

### Recommended Tools

**For Static Screenshots:**
- macOS: Command + Shift + 4
- Windows: Snipping Tool or Windows + Shift + S
- Linux: GNOME Screenshot or Spectacle

**For GIF Recordings:**
- [LICEcap](https://www.cockos.com/licecap/) - Free, simple screen recorder (Windows & macOS)
- [ScreenToGif](https://www.screentogif.com/) - Feature-rich recorder (Windows)
- [Peek](https://github.com/phw/peek) - Simple animated GIF recorder (Linux)
- [Kap](https://getkap.co/) - Open-source screen recorder (macOS)

## What to Capture

### High-Priority Screenshots

1. **feed.gif** - OnlyFood swipeable feed in action (10-15 seconds)
2. **image-search.png** - Image-to-dish search interface with results
3. **calendar.png** - Calendar integration showing meal suggestions
4. **cart.png** - Shopping cart with ingredient ordering
5. **homepage.png** - Landing page/main interface

### Tips for Great Screenshots

- **Use real data** - Show the app in action with actual dishes and data
- **High resolution** - Use 1920x1080 or higher for screenshots
- **Keep GIFs short** - 10-15 seconds max, focus on one feature
- **Optimize file size** - Use tools like [TinyPNG](https://tinypng.com/) for images
- **Show interactions** - Capture mouse clicks, typing, and navigation in GIFs
- **Good lighting** - Ensure UI elements are clearly visible

## File Naming Convention

Use descriptive, lowercase names with hyphens:
- ✅ `onlyfood-feed.gif`
- ✅ `image-search-results.png`
- ✅ `calendar-integration.png`
- ❌ `Screenshot 2026-01-28.png`
- ❌ `IMG_1234.png`

## Updating README

After adding screenshots, update `/README.md`:

1. Uncomment the image tags in the "Screenshots & Demo" section
2. Update paths to match your screenshot filenames
3. Add descriptive alt text for accessibility

Example:
```markdown
![OnlyFood Feed](./docs/screenshots/onlyfood-feed.gif)
*Swipeable TikTok-style food discovery feed with AI ranking*
```
